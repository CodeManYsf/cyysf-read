# Obsidian知识库使用说明

这个文件夹现在可以直接作为 Obsidian vault 打开。

## 第一次打开

1. 打开 Obsidian。
2. 选择“打开本地文件夹作为库”。
3. 选择 `C:\Users\yisif\Desktop\阅读`。
4. 打开 [[知识库入口]]。

## 日常使用

每天阅读结束后，优先更新这些地方：

1. `01_书籍记录/<书名>/02_每日思考/`：当天 1-3 条思考种子。
2. [[本周阅读工作台]]：暂时不处理、但值得每周整理的内容。
3. `02_主题知识库`：每周只更新真正有增量的主题卡片。
4. `03_行动实践库`：只记录真正能指导现实行为的原则和实践。
5. [[GitHub同步流程]]：重要记录完成后及时提交并推送到 GitHub。

## Obsidian 能提供什么

- 用双链把书籍、主题、行动原则连起来。
- 用 Base 查看每日复盘、主题卡片、书籍实践状态。
- 用 Canvas 查看阅读系统的整体结构。
- 用标签和属性支持后续筛选、统计和复盘。

## 维护原则

1. 正文保持自然表达，属性只负责让系统更好检索。
2. 新增每日思考时，优先使用 [[每日思考模板]]。
3. 新增主题时，优先使用 [[主题卡片模板]]。
4. 每天不强制主题落库，每周集中整理。
5. 读完一本书后，要回到读前目标做复盘；A 档书再做 [[整书脉络模板]]。
