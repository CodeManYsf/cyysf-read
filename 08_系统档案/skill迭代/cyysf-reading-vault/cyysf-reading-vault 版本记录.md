# cyysf-reading-vault 版本记录

## v0.8 - 2026-06-04

本次重构重点：

1. 仓库目录从流程文档驱动，调整为记录库驱动。
2. 新增 `vault.config.yaml`，作为仓库和 skill 的接口。
3. 每本书拥有统一记录结构：总览、读前目标、每日思考、阶段复盘、读后总结、整书脉络、方法实践。
4. 每日机制从“处理所有划线”调整为“保留 1-3 条思考种子”。
5. 每周机制承担主题卡片、行动实践和阶段复盘整理。
6. 奖励机制暂停，不再作为当前系统功能。
7. 多智能体协作记录迁移到 `08_系统档案/多智能体协作记录/`。
8. 新增 skill 迭代归档区，保留安装版 skill 的源码快照。

## 后续版本方向

1. 让 skill 更熟练地根据 `vault.config.yaml` 自动判断写入位置。
2. 增强“行动实践是否落地”的追踪。
3. 支持不同智能体平台按同一仓库规则协作。
4. 继续降低日常维护成本，把系统重心放在每日思考和每周整理。
