# skill接口约定

`vault.config.yaml` 是仓库和 `cyysf-reading-vault` skill 之间的接口。

## skill 启动时读取

1. `README.md`
2. `AGENTS.md`
3. `vault.config.yaml`
4. `00_入口/知识库入口.md`

如需具体执行，再读取：

- `00_入口/本周阅读工作台.md`
- `07_索引/方法系统索引.md`
- 相关书籍目录
- 相关主题、行动或系统档案

## 同步约定

产生文件改动后：

1. 写平台协作记录。
2. `git status --short`
3. `git add .`
4. `git commit -m "[平台] 类型：YYYY-MM-DD 主题"`
5. `git push`

如果拉取、提交或推送失败，不强行覆盖，先说明原因。
