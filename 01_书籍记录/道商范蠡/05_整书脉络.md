# 《道商范蠡》整书脉络

状态：待快速二刷后完善。

## 核心问题

这本书要回答的核心问题可以理解为：

```text
范蠡如何在乱世、权力、屈辱、成功和财富中，始终保持行动力、判断力和进退感？
```

## 人生主线

```text
离楚入越
-> 不受重视但下基层做实事
-> 越国战败，随越王入吴受辱
-> 协助越国复兴并击败吴国
-> 功成身退
-> 转入商业，成为陶朱公
-> 多次散财再起
```

## 初步结构分段

### 第一部分：入局

范蠡离开原有处境，进入越国，在不受重视时仍然行动。

### 第二部分：受辱与蓄势

越国战败后，范蠡与越王承受屈辱，在低谷中保持长期目标。

### 第三部分：复兴与成事

范蠡协助越国复兴，体现判断局势、组织资源、借势成事的能力。

### 第四部分：功成身退

越国成功后，范蠡看见风险，选择退出权力场。

### 第五部分：商业重启

范蠡进入商业世界，以信用、品牌、利益分配和节制继续成事。

## 快速二刷时要补的问题

1. 每个阶段对应哪些章节？
2. 每个阶段的关键选择是什么？
3. 每个选择背后的原则是什么？
4. 商业部分如何承接前面的人生智慧？
5. 我的划线分别落在开端、转折、结论还是局部触动？
