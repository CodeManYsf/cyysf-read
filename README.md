# cyysf-read

个人阅读知识库与阅读方法实践仓库。

这个仓库用来长期保存我的读书记录、读前目标、每日思考、阶段复盘、读后总结、主题卡片、行动实践和方法迭代。它不是为了追求“读了多少本书”，而是为了让阅读真正转化成可以复盘、可以行动、可以迁移的认知资产。

## 核心定位

```text
仓库负责记录，skill 负责执行。
```

本仓库只保存阅读成果、模板、索引和系统档案；具体的阅读协助、提问、分析、整理、归档和 GitHub 同步，由 `cyysf-reading-vault` skill 执行。

微信读书划线和笔记输入由独立的 `weread-skills` 提供，它只是可选输入工具，不属于本仓库内置能力。

## 当前阅读方法

当前方法强调“先有自己的思考，再让智能体整理”。

1. 读前先写目标：为什么读这本书，希望它回答什么问题。
2. 读前判断读法：A 精读 / B 正常读 / C 轻读。
3. 每天轻量记录：只保留 1-3 条真正有触动的思考种子。
4. 每周集中整理：再处理主题卡片、行动实践和阶段复盘。
5. 读完回到目标：检查最初的问题是否被回答。
6. A 档书再做整书脉络：用快速二刷梳理全书结构。
7. 行动实践闭环：追踪读到的原则有没有进入现实。
8. GitHub 同步：重要记录完成后提交并推送，保证资料可迁移。

## 新环境恢复

换电脑或换平台时，先克隆仓库：

```bash
git clone https://github.com/CodeManYsf/cyysf-read.git
```

然后安装或准备：

```text
必需：cyysf-reading-vault
可选：weread-skills
```

打开 Obsidian 时，将仓库目录作为 vault 即可。

## 多智能体协作

Codex、WorkBuddy 或其他智能体平台都可以维护这个仓库，但必须遵守同一套规则。

开始前读取：

1. [README.md](README.md)
2. [AGENTS.md](AGENTS.md)
3. [vault.config.yaml](vault.config.yaml)
4. [知识库入口](00_入口/知识库入口.md)

基本原则：

1. GitHub 仓库是唯一事实来源。
2. 阅读内容写入统一记录目录，不按平台拆分。
3. 平台操作记录写入 `08_系统档案/多智能体协作记录/<平台>/`。
4. 用户先思考，智能体后整理。
5. 不强推、不覆盖、不删除其他平台或用户已有记录。

标准同步流程：

```bash
git status
git pull --ff-only
git add .
git commit -m "[平台] 类型：YYYY-MM-DD 主题"
git push
```

## 设计原则

这个系统追求的是长期可坚持，而不是短期整理得很漂亮。

```text
每日轻量积累，每周集中整理，读后回到目标，最终落到行动。
```
