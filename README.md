# 阅读知识库

这是我的个人阅读记录库，用来保存读前目标、每日思考、阶段复盘、书籍总结、主题卡片、行动实践和方法迭代。

当前设计原则是：

```text
仓库负责记录，skill 负责执行。
```

也就是说，本仓库不再承担大量“怎么执行”的长文档职责；执行流程由 `cyysf-reading-vault` skill 读取本仓库的 `vault.config.yaml` 后完成。

## 迁移方式

换电脑后，只需要：

```bash
git clone https://github.com/CodeManYsf/cyysf-read.git
```

然后安装：

```text
必需：cyysf-reading-vault
可选：weread-skills
```

`weread-skills` 只负责微信读书划线和笔记输入，不属于本仓库内置能力。

```text
07_索引/             书籍、主题、行动、方法索引
08_系统档案/         方法迭代、协作记录、同步规则、skill 迭代
99_归档/             历史或暂停内容
vault.config.yaml    skill 和仓库的接口约定
```

## 当前阅读方法

核心机制：

1. 读前目标：先想清楚为什么读。
2. 读法判断：A 精读 / B 正常读 / C 轻读。
3. 每日轻量：只保留 1-3 条思考种子。
4. 每周整理：集中处理主题、行动和阶段复盘。
5. 读后闭环：回到读前目标，确认最终档位。
6. 行动实践：追踪阅读原则是否真的进入现实。
7. GitHub 同步：每次重要记录后提交并推送。

详细执行逻辑由 `cyysf-reading-vault` skill 负责。

## 多智能体协作

Codex、WorkBuddy 或其他智能体都可以维护本仓库，但必须遵守：

1. 先同步 GitHub。
2. 阅读 `README.md`、`AGENTS.md` 和 `vault.config.yaml`。
3. 阅读内容写入统一记录目录，不按平台拆分。
4. 平台操作记录写入 `08_系统档案/多智能体协作记录/<平台>/`。
5. 不强推、不覆盖、不删除用户或其他平台记录。

一句话：

```text
阅读内容统一沉淀，平台操作单独留痕。
```
