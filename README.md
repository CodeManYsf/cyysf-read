# 阅读知识库

这是一个个人阅读知识库项目，用来记录读前目标、每日阅读回收、主题卡片、行动原则、书籍复盘和阅读方法迭代。

它的目标不是追求读书数量，而是让阅读真正转化成理解力、判断力、表达力和行动能力。

## 当前定位

这个知识库同时承担两个角色：

1. **阅读记录系统**：记录每本书从读前目标到读后复盘的完整过程。
2. **阅读方法实验场**：用连续 5 本书测试并优化一套适合自己的阅读方法，成熟后再考虑封装成 skill。

当前第一本实践书籍是《道商范蠡》。

## 核心原则

1. **你先思考，AI 后整理**  
   Codex 不直接替我总结，而是在我表达理解后，帮助我归纳、追问、落库。

2. **按问题读书，而不是按书读书**  
   每本书开始前先记录为什么读、希望回答什么问题、读完希望发生什么变化。

3. **按主题沉淀，而不是只按日期保存**  
   每日复盘只是入口，真正长期有价值的是主题卡片和行动原则。

4. **把阅读转化为行动**  
   好的划线最终要尽量变成现实场景中的判断、提醒或行动原则。

5. **及时同步到 GitHub**  
   每次完成回顾、总结或方法调整后，都要提交并推送，避免换电脑或本地异常导致资料丢失。

## 日常阅读流程

1. 阅读 20 分钟。
2. 拉取当天微信读书划线。
3. 先按主题分组，不急着总结。
4. 我选择要讨论的一组或一条。
5. 我先回答为什么有感触、连接了什么经历、想提醒自己什么。
6. Codex 再整理成每日回收、主题归属和行动原则。
7. 更新对应书籍卡片、主题卡片或行动原则。
8. 按 [[GitHub同步流程]] 提交并推送。

## 每本书闭环

每本书至少留下：

1. 读前目标
2. 每日阅读回收
3. 书籍卡片
4. 主题卡片更新
5. 1-3 条行动原则
6. 读后目标回顾
7. 方法迭代记录

## Obsidian 使用

这个目录可以直接作为 Obsidian vault 打开。

第一次打开时：

1. 打开 Obsidian。
2. 选择“打开本地文件夹作为库”。
3. 选择本目录。
4. 打开 [[00_知识库入口]]。

## GitHub 同步

当前目标是将整个阅读知识库迁移到 GitHub，作为长期备份和版本记录。

首次迁移前，本目录需要初始化为 Git 仓库，并绑定 GitHub remote。完成初始化后，每次复盘结束执行：

```bash
git status
git diff --stat
git add README.md 00_知识库入口.md 00_阅读系统与模板 01_每日阅读回收 02_每周阅读复盘 03_书籍卡片 04_主题卡片库 05_行动原则库 07_Obsidian视图 08_模板 09_索引
git commit -m "阅读复盘：YYYY-MM-DD 主题"
git push
```

更详细的流程见 [[GitHub同步流程]]。

## 当前方法状态

- 奖励机制和积分功能已停用。
- 当前保留的核心机制是：读前目标、划线讨论、每日回收、主题落库、行动原则、读后复盘、GitHub 同步。
- 后续优化重点是降低维护成本，同时保证每次真正有价值的思考都能留下来。
