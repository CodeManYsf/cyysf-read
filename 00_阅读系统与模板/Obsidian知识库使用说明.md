# Obsidian知识库使用说明

这个文件夹现在可以直接作为 Obsidian vault 打开。

## 第一次打开

1. 打开 Obsidian。
2. 选择“打开本地文件夹作为库”。
3. 选择 `C:\Users\yisif\Desktop\阅读`。
4. 打开 [[00_知识库入口]]。

## 日常使用

每天复盘结束后，优先更新这些地方：

1. `01_每日阅读回收`：当天复盘。
2. [[道商范蠡_方法实践记录]]：书籍实践进度。
3. `04_主题卡片库`：只更新 1-3 张真正有增量的主题卡片。
4. `05_行动原则库`：只记录真正能指导现实行为的原则。
5. [[GitHub同步流程]]：复盘完成后及时提交并推送到 GitHub。

## Obsidian 能提供什么

- 用双链把书籍、主题、行动原则连起来。
- 用 Base 查看每日复盘、主题卡片、书籍实践状态。
- 用 Canvas 查看阅读系统的整体结构。
- 用标签和属性支持后续筛选、统计和复盘。

## 维护原则

1. 正文保持自然表达，属性只负责让系统更好检索。
2. 新增每日复盘时，优先使用 [[每日阅读回收模板]]。
3. 新增主题时，优先使用 [[主题卡片模板]]。
4. 主题分类必须落库，不能只停留在聊天里。
5. 读完一本书后，要回到读前目标做复盘。
