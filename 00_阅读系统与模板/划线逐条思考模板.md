# 划线逐条思考模板

用途：当我让 Codex 列出本周/某本书的划线后，不急着让它直接总结，而是按这套模板逐条思考、追问、讨论，最后再沉淀为周复盘、书籍卡片、主题卡片和行动原则。

## 使用原则

1. 先理解自己为什么被打动，再决定要不要记录。
2. 先讨论，再总结；先生成自己的判断，再让 Codex 帮我整理。
3. 每条划线最多归入 1-2 个主题，不到处复制。
4. 不是所有划线都要转成行动，只有真正能改变判断或行为的才进入行动原则库。
5. 如果这本书有读前目标，每条划线都要检查它是否回应了读前提出的问题。

## Codex 逐条讨论流程

当我说“按模板逐条分析这些划线”时，Codex 按以下方式进行：

1. 先列出本次要讨论的划线编号。
2. 每次只讨论 1 条，不一次性替我总结全部。
3. 对每条划线，先问我 2-4 个问题，帮助我说出自己的理解。
4. 等我回答后，再帮我整理为：
   - 为什么有感触
   - 它回答的问题
   - 它和读前目标的关系
   - 可用判断
   - 可选行动原则
   - 归入主题
5. 如果一条划线没有明显行动价值，只沉淀为主题理解，不强行变成行动。
6. 全部讨论完后，再统一生成周复盘、书籍卡片、主题卡片和行动原则。

## 每条划线的讨论提问库

Codex 可以从下面的问题里选 2-4 个来问，不必每次全部问完。

### 感触来源

1. 你第一眼觉得这句话好在哪里？
2. 它让你想到最近的哪件事？
3. 它击中的是情绪、经验，还是判断？
4. 如果不用书里的话，你会怎么说这层意思？

### 现实连接

1. 这句话能对应到你的工作、关系、职业选择或自我状态吗？
2. 你最近有没有一个场景，正好需要这句话里的提醒？
3. 它更像是在解释过去，还是指导下一步？

### 判断校准

1. 你完全同意它吗？有没有例外？
2. 它有没有说得太绝对？
3. 如果把它用错，会带来什么风险？
4. 它和你原来的想法有什么不同？

### 行动转化

1. 这句话未来 7 天能不能用一次？
2. 如果能用，最具体的场景是什么？
3. 你要做的动作是什么，而不是只记住这句话？
4. 怎么判断你真的用了它？

### 主题归类

1. 以后你最可能在哪个问题下调用这条笔记？
2. 它更像是关于人性、沟通、逆境、战略，还是自我修炼？
3. 它可以和之前哪条笔记连接起来？
