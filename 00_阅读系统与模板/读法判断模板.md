# 读法判断模板

用途：帮助我判断一本书应该精读、正常读、轻读还是暂停。读法不是由书的名气决定，而是由它对我当前问题、行动和长期主题的价值决定。

## 一句话原则

```text
书的读法，不由书的名气决定，而由它对我当前问题、行动和长期主题的价值决定。
```

## 三次判断

### 1. 读前定档

开始一本书前，先判断它暂时属于哪一档。

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 问题相关度 | 和当前问题关系弱 | 有间接关系 | 强烈回应当前问题 |
| 认知增量预期 | 大概率只是重复常识 | 可能有一些新观点 | 可能改变我的判断 |
| 行动价值预期 | 不太会影响行动 | 可能带来提醒 | 可能产生具体行动原则 |
| 结构价值预期 | 不需要学习结构 | 结构可能有参考 | 结构值得二刷梳理 |
| 复读意愿 | 不想二刷 | 读后再看 | 读完后愿意快速二刷 |

总分：

初始档位：

```text
8-10 分：A 档，精读
5-7 分：B 档，正常读
0-4 分：C 档，轻读或试读
```

默认规则：默认 B 档。除非它强烈回应我的现实问题，否则不默认 A 档。

### 2. 读到 20%-30% 时复判

读前判断可能会错，所以读到 20%-30% 时必须复判一次。

```text
这本书是否还在回答我的读前问题？
我有没有频繁产生“这个对我有用”的感觉？
它有没有改变我原来的判断？
它是有结构地展开，还是只是观点堆叠？
我是否愿意读完后再快速二刷？
```

复判结果：

```text
维持当前档位：
升级：
降级：
暂停：
原因：
```

### 3. 读后确认

读完后，再确认最终档位。

```text
最终档位：A / B / C
是否需要快速二刷：
是否需要整书脉络卡：
是否需要行动实践：
是否需要主题卡片：
```

## A/B/C 档处理方式

### A 档：精读书

适合：

- 和当前人生、工作、关系或长期问题强相关。
- 读的时候不断产生触动。
- 能改变判断。
- 能产生行动原则。
- 结构本身值得学习。
- 值得快速二刷。

处理方式：

1. 读前目标。
2. 每日思考种子。
3. 读后总结。
4. 行动实践。
5. 快速二刷。
6. 整书脉络卡。
7. 主题卡片沉淀。

### B 档：正常读

适合：

- 有启发。
- 能带走几个观点。
- 但不值得二刷。
- 不需要梳理完整结构。

处理方式：

1. 读前简单目标。
2. 少量思考种子。
3. 读后书籍卡片。
4. 1 条行动原则。
5. 必要时更新主题卡片。

### C 档：轻读书

适合：

- 只是扩展见闻。
- 信息密度一般。
- 只有少数句子打动我。
- 暂时不影响行动。

处理方式：

1. 只保留触发点。
2. 不做完整总结。
3. 不做整书脉络。
4. 不强制读完。

## Codex 协作要求

当我开始新书时，Codex 要先引导我完成读前定档。

当我读到 20%-30% 时，Codex 要提醒我做一次读法复判。

当我读完一本书时，Codex 要根据最终档位决定后续工作量，不要把每本书都默认做成 A 档精读。
