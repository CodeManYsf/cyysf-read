# 划线逐条思考方法迭代记录

用途：记录“划线逐条思考模板”的实际使用效果、问题、调整和版本演进。等这个方法经过一段时间验证，足够稳定、好用、可复用后，再封装成 Codex skill。

关联模板：[划线逐条思考模板.md](./划线逐条思考模板.md)

## 方法当前版本

版本：v0.2

创建日期：2026-05-23

当前定位：阅读划线后的深度思考与讨论流程。

核心目标：

1. 不让 Codex 直接替我总结，而是先逼出我自己的思考。
2. 把每条划线从“我觉得好”推进到“它为什么打动我、它能改变什么判断、它能不能变成行动”。
3. 在读书前先记录阅读目标，读完后回到最初目标做复盘。
4. 最后再由 Codex 帮我整理成周复盘、书籍卡片、主题卡片和行动原则。

## 当前流程摘要

1. Codex 先列出本次要讨论的划线编号。
2. 如果这本书有读前目标，Codex 先调出或询问读前目标。
3. 每次只讨论 1 条划线。
4. Codex 先问 2-4 个问题，不直接总结。
5. 我回答后，Codex 再整理为：
   - 为什么有感触
   - 它回答的问题
   - 它和读前目标的关系
   - 可用判断
   - 可选行动原则
   - 归入主题
6. 全部讨论完后，再统一沉淀为：
   - 周复盘
   - 书籍卡片
   - 主题卡片
   - 行动原则

### 第 1 次试用

日期：2026-05-23 起

书籍/范围：《道商范蠡》，仅记录 2026-05-23 起的新增阅读与划线，不追溯此前阅读内容

讨论划线数量：先从每周 3-5 条重点划线开始

实际体验：Day 1 已完成。今天回顾 8 条划线，逐条讨论后能明显引出个人经验和现实问题，比直接总结更有价值。

哪些地方好用：先让用户回答，再由 Codex 整理，能保留用户自己的思考；多条相关划线可以合并讨论，节奏更自然。

哪些地方卡住：如果逐条都按完整模板，会有些慢；概念连续的划线适合合并处理。

是否产生了我自己的新判断：产生了。AI 只能辅助分析和归纳，最有价值的思考必须由自己参与；难而正确的事要从容易启动处开始。

是否产生了可执行行动：产生了。每天读 20 分钟，读后至少整理 1 条划线或 1 个想法；面对客户不确定问题时先确认再答复，不冒进。

需要调整：后续允许把连续概念划线合并讨论；每天回收不追求多，只抓最关键 1-3 条沉淀。

1. 每天阅读 20 分钟。

## 实用性评估维度

每次使用后，可以按 1-5 分简单打分。

1. 激发思考：它有没有让我说出原本没想清楚的东西？
2. 追问质量：Codex 的问题是不是刚好，不空泛、不压迫？
3. 节奏控制：一条一条讨论是否舒服，是否太慢或太碎？
4. 行动转化：讨论后是否能形成具体行动或判断？
5. 沉淀质量：最后生成的记录是否方便以后调用？
6. 使用负担：整个流程是否轻，不会让我觉得麻烦？

## 可能的优化方向

1. 增加“快速模式”：每条只问 1-2 个问题，适合时间少的时候。
2. 增加“深度模式”：针对特别重要的划线，展开到现实案例、反例和行动设计。
3. 增加“只做主题归类模式”：适合大量划线初筛，不做深度讨论。
4. 增加“行动复盘模式”：一周后回看行动原则是否真的被使用。
5. 增加“反对意见环节”：防止把书里的话直接当成正确结论。
6. 增加“读前目标模式”：开始新书前先记录目的、问题、现实场景和阅读策略。
7. 增加“目标回顾模式”：读完后先对照读前目标，再做总结。
8. 增加“GitHub 同步机制”：每天复盘或总结后提交并推送，避免知识库只停留在本地。
9. 增加“主题落库机制”：每天复盘后把最重要的 1-3 个主题同步写入主题卡片库。

## 封装成 skill 前的判断标准

当满足以下条件时，可以考虑把它封装成 skill：

1. 至少实际使用 3 次。
2. 覆盖至少 2 本书或 2 个不同阅读主题。
3. 每次使用后都能产出比直接总结更有价值的个人判断。
4. 流程不会显得繁琐，能自然进入对话。
5. 提问方式稳定，不需要每次重新解释。
6. 输出格式稳定，能直接进入阅读系统目录。
7. 已经明确哪些内容进入周复盘，哪些进入书籍卡片，哪些进入主题卡片，哪些进入行动原则。
8. 已经验证读前目标记录和读后目标回顾确实能提升阅读质量。
9. 已经验证 GitHub 同步机制能稳定保存知识库，并且不会显著增加复盘负担。
10. 已经验证主题落库机制能让主题卡片库真正形成可检索的知识网络。

## 未来 skill 设想

名称候选：

- reading-reflection-coach
- highlight-thinking-coach
- 划线思考教练

技能定位：

帮助用户从读前目标、微信读书划线和读后复盘出发，通过目标记录、逐条提问、现实连接、判断校准和行动转化，把阅读从“收藏好句”变成“形成自己的认知资产”。

skill 应具备的能力：

1. 拉取或接收划线列表。
2. 在新书开始前，引导用户说清楚读书目的、核心问题、现实场景和阅读策略。
3. 保存读前目标，并在读中/读后持续引用。
4. 按编号逐条引导用户思考。
5. 根据用户回答整理结构化记录。
6. 自动判断是否值得进入行动原则库。
7. 自动归入长期主题。
8. 读完后先回顾读前目标，再生成周复盘、书籍卡片、主题卡片和行动原则。
9. 每日复盘结束后提醒或执行 GitHub 同步，包括查看改动、提交和推送。
10. 每日复盘结束后更新主题卡片库，保留最重要的 1-3 个主题沉淀。
11. 保留方法迭代记录，持续改进提问方式、输出格式、主题落库和同步流程。

## 下一步

下一次使用时，先选择 3-5 条划线做小规模试验，不急着处理全部划线。

试验重点：

1. Codex 的提问是否能激发我自己的思考。
2. 每条讨论的长度是否合适。
3. 最终沉淀是否比直接总结更有价值。
4. 读前目标是否能让划线和复盘更聚焦。
